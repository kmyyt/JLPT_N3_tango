오답노트

퀴즈·주관식에서 틀린 단어가 자동 기록되며 누적 오답 횟수를 확인할 수 있습니다.

탭별 기능 안내

  • 대시보드: 전체 어휘 수, 외움·헷갈림·미암기 수, 즐겨찾기 수, 누적 오답 수를 한눈에 보고 클릭해 해당 목록/복습으로 이동합니다. 커스텀 단어장 생성과 데이터 백업·복원·초기화를 지원합니다.
  • 단어장: 기출 연도/분류·품사·암기 상태·단어장 필터 및 정렬을 제공합니다. 중복 단어가 여러 연도·분류에 등장한 경우 n년·n년도 중복 기출로 표기하며, 품사 메모 수정, 3단계 암기 상태 변경, 체크박스 다중 선택 후 새 단어장 저장, 즐겨찾기 모아보기가 가능합니다.
  • 플래시카드: 셔플과 앞면 표기/읽기, 뒷면 품사 및 예문 1개(예문 읽기·해석 토글 및 전역 가림 연동), 3단계 암기 상태 변경, 체크박스 다중 선택 후 새 단어장 저장, 일본어 TTS 재생을 지원합니다.
  • 4지선다 퀴즈: 출제 문항 수와 범위(전체·즐겨찾기·커스텀 단어장·암기 상태) 및 셔플을 설정해 어휘 자료 기반 문항과 오답 보기로 실전 연습을 할 수 있습니다.
  • 주관식 테스트: 출제 범위·문항 수·셔플·뜻 숨김·첫글자 힌트를 설정하고 히라가나 직접 입력 또는 타일 순서 클릭(한 글자 지우기/전체 초기화)으로 답합니다.
  • 오답노트: 틀린 단어 자동 기록, 단어별 누적 오답 횟수 확인, 전역 가림 연동, 오답 단어만 재도전 및 복습 완료 처리를 제공합니다.

전역 가림 · 히라가나 전용 단어 예외 규칙 · 데이터 관리

  • 전역 가림 연동: 상단 툴바의 전체 읽기 가림과 전체 뜻 가림 토글은 단어장, 플래시카드, 오답노트 등 학습 화면의 읽기·뜻 표시에 연동됩니다.
  • 히라가나 전용 단어 예외 규칙: 표기가 히라가나로만 된 단어는 주관식 테스트에서 한글 뜻을 제시하고 히라가나 직접 입력 또는 히라가나 타일 순서 선택으로 출제됩니다.
  • 데이터 관리: 학습 상태와 커스텀 단어장, 오답 기록은 브라우저 저장소에 유지되며 JSON 파일로 백업·복원하거나 전체 초기화할 수 있습니다.
